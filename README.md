# 🌱 A Mindfulness + Productivity App  

A simple app to help track habits, focus, and well-being.  
Built with **Vite + React**, deployed on **Hugging Face Spaces**.  

## 🚀 Features
- Productivity tracking
- Mindfulness prompts
- Simple, clean UI

## ⚡ Tech Stack
- React + Vite  
- Hugging Face Spaces (Static)
